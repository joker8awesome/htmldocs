새 주제를 정리할 때 쓰는 기본 골격입니다. TL;DR, 접히는 섹션, 탭 코드 블록, 복사 버튼, 비교 테이블이 포함되어 있고 전부 이 파일 하나 안에서 동작합니다.

02접히는 상세 긴 내용용

왜 마크다운 대신 HTML인가

마크다운은 구조를 평면화합니다. 비교·다이어그램·상태 같은 공간적 정보는 렌더링된 문서에서 훨씬 빨리 읽힙니다. 그리고 HTML 파일은 브라우저만 있으면 어디서든 열립니다.

접힌 섹션은 기본으로 닫아둔다
